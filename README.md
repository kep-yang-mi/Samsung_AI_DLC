# 삼성_AI_DLC

삼성전자 삼성 계정 팀의 AI-DLC 적용 사례를 한 페이지로 재구성한 비공식 업무 참고 자료입니다.

## 열어 보기

[index.html](./index.html)을 내려받아 브라우저로 열면 됩니다. 설치나 인터넷 연결은 필요하지 않습니다.

## 다루는 내용

- 개발 단계별 사람과 AI의 역할, 승인과 산출물
- 머지 전 테스트, 점진적 릴리스, 배포 후 사용자 행동 관찰
- 운영 에이전트의 읽기 권한과 프로덕션 변경 승인 경로
- Second Brain의 지식 정제와 다음 개발로의 환류

발표 장표를 캡처하지 않고 HTML과 SVG로 도식을 제작했으며, 디자인은 Meta [Astryx](https://astryx.atmeta.com/docs/principles)를 참고했습니다. 발표 수치의 적용 범위는 페이지 하단에 명시했습니다. 원본 녹음 및 공유 접근 링크는 포함하지 않습니다.
